# 平台策略目录

## 快照与兼容性

| 目录版本 | 内容 | 用途 |
| --- | --- | --- |
| `2026-11-04.1` | 原始 Amazon / Shopee / TikTok 共 9 个站点 | T45 前历史环境迁移后固定使用 |
| `2026-11-06.1` | 原策略逐字段不变，追加 Amazon CA、Shopee TW、TikTok JP | 新环境及用户显式切换站点时使用 |

目录定义位于 `packages/core/src/platform-policy-catalog.ts`。新增或调整策略时，必须追加新的
`PlatformPolicyCatalog` 快照并更新当前版本；**禁止就地修改已经发布的快照**。测试对完整目录 JSON
计算固定 SHA-256，同时检查历史站点在新快照中逐字段不变、返回值为防御性副本。

新增站点进入目录只表示站点 URL、出口地区、语言和时区建议已配置，不代表该平台已经通过真实
账号、验证码或地区代理验收。公开站点验收仍由 T40 的独立证据记录。

## 环境固定与迁移

- `BrowserProfile.platformPolicyVersion` 是环境使用的目录版本，不由渲染层直接编辑。
- 新建带平台的环境固定到当前目录；普通环境不占用目录版本。
- SQLite migration 11 将已有平台环境一次性固定到 `2026-11-04.1`，并写入
  `migration:platform-policy-version` 审计，重启不会重复回填或跟随当前版本。
- 用户显式执行“切换站点”时，使用当前目录重选站点并更新固定版本；审计记录切换前后版本。
  普通编辑启动页或平台会脱离一键站点策略，不隐式继承区域约束。
- 启动区域闸门按环境固定快照查找站点，未知站点或目录版本会明确报错，不回退到当前目录。

## 加密备份

环境版本字段随现有加密备份载荷一起保存。旧备份没有该字段时，固定到导入时的当前目录；已经固定
的版本原样恢复。未知版本、未知站点或平台与站点不匹配均拒绝导入，不静默改写为其他策略。

## 更新检查

1. 在 `packages/core/src/platform-policy-catalog.ts` 追加新快照，不改旧快照。
2. 更新 `CURRENT_PLATFORM_POLICY_CATALOG_VERSION`，并同步新快照的固定哈希测试。
3. 为新地区补充 `checkPlatformRegion()` 测试及桌面选项测试。
4. 获得匹配地区代理后，单独执行真实公开站点验收；没有证据时不得标记为站点已验收。
5. 提交前执行 `pnpm typecheck && pnpm test`，涉及桌面交互时执行对应 Electron smoke。
